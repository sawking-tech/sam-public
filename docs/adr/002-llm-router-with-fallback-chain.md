# ADR-002: Модель выбирает роутер по виду задачи, с цепочкой запасных поставщиков

**Статус:** принято


## Контекст

У SAM несколько поставщиков с разной ценой и доступностью: локальный LM Studio бесплатен, но зависит от
того, что загружено; Gemini, DashScope и Anthropic API платные и упираются в квоты; Claude Code CLI идёт
по подписке, лимиты которой делятся с работой автора (1864a74). Главному агенту нужен быстрый ответ,
планированию - точный структурированный JSON. Любой поставщик может отказать посреди разговора: 429, 403,
500.

## Решение

Каждый вызов LLM называет вид задачи, `gateway/llm_router.py` выбирает по нему поставщика и идёт по цепочке
запасных, `gateway/llm_client.py` помнит отказы поставщиков и меняет поставщика посреди вызова.

- Виды задач: `fast` - быстрая модель голосового хода (ADR-014), `turn` - главный ход (агент за ACP, ADR-022, или
  как `default`), `planning` - точный структурный JSON, `default` - остальное. Цепочка своя у каждого вида.
- `LLM_SOURCE` принудительно выбирает поставщика; недоступен - обычная цепочка.
- Отказ поставщика (429, 403, 5xx, молчание) - пауза этого поставщика и замена следующим по цепочке.

Цепочки, паузы, сроки молчания и переменные - `docs/features/llm-router.md`.

## Рассмотренные варианты

**Claude Code CLI выше в цепочке planning.** Отклонён в 1864a74: лимиты подписки общие, CLI - последний
запасной.

Других вариантов (один поставщик, внешний роутер) в истории не видно.

## Риски и что с ними делаем

| Риск | Что происходит | Чем закрыт |
|---|---|---|
| LM Studio отдаёт первую загруженную модель | Поведение зависит от порядка загрузки | Модель по id `LMSTUDIO_MODEL`, без него - только единственная загруженная (SAM-57) |
| Модель тихо сменилась посреди сессии | Ответы другого качества и формата вызовов | `/health` показывает поставщика и модель; события в мониторе |
| Квота кончилась у всех | Ход падает | Не закрыт; ошибка в лог |

## Последствия

| Обязывает | Что даёт |
|---|---|
| Новый поставщик добавляется в роутер: источник, конфиг, место в цепочке | Отказ одного поставщика не останавливает SAM |
| Вызов LLM идёт через `llm_client` | Пауза после 429 и выключение после 403 действуют для всех вызовов |
| Вызывающий код указывает вид задачи | Дорогая точная модель тратится только там, где нужна |

| Запрещает или ограничивает | Чем платим |
|---|---|
| Вызов SDK поставщика в обход роутера и `llm_client` | Каждый поставщик заводится в двух модулях |
| Claude Code CLI - только последний запасной | Сильная модель доступна только при отказе остальных |
| Качество ответа зависит от того, кто сейчас ответил | Поведение SAM меняется без смены кода |
