# ADR-009: Долгая память: MongoDB - источник правды, Qdrant - оглавление по фасетам

**Статус:** принято


## Контекст

SAM помнит факты о доме, людях и договорённостях. Векторный поиск находит факт по смыслу, но вектор
привязан к модели эмбеддингов, а текст в payload Qdrant устаревает при правке факта. Один факт отвечает на
разные вопросы («когда у Мурки день рождения», «какого он цвета»), а один вектор на факт матчит их хуже.

## Решение

`gateway/rag.py`, класс `RAGStore` (38451af):

- MongoDB (`_memories`) - источник правды: полный текст, стабильный `_id`, теги, счётчики доступа.
- Qdrant - оглавление: один факт - несколько точек (summary и вопросы, которые факт закрывает); вектор можно
  пересобрать из Mongo в любой момент.
- Поиск гибридный: вектор по фасетам и слова (BM25), слияние, текст и признак архива - всегда из Mongo (SAM-102).
- Сбой эмбеддера или размерности - явная ошибка, а не тихий нулевой вектор.
- Эмбеддер - отдельный долгоживущий процесс, без него - модель в шлюзе (SAM-172).

Запись, шаги поиска, пороги, эмбеддер и обслуживание - `docs/features/memory/memory-search.md`.

## Рассмотренные варианты

**Синхронизация через MongoDB Change Streams.** Отклонена: расхождение Qdrant и Mongo чинит dream-job
(SAM-22) (`docs/architecture/context/compression.md`, «Чего не делать»).

**Memory MCP от Anthropic (граф сущностей).** Отклонён в SAM-47: Mongo, Qdrant и `related_ids` уже есть,
граф строится поверх них (SAM-45).

**Один вектор на факт.** Был до 38451af; заменён фасетами, чтобы запрос матчил вопрос, а не общий текст.

## Риски и что с ними делаем

| Риск | Что происходит | Чем закрыт |
|---|---|---|
| Qdrant отстал от Mongo | Поиск не находит новый факт или находит удалённый | Текст и признак архива всегда из Mongo; `reindex_all` |
| Смена модели эмбеддингов | Размерность не совпала | `DimensionMismatchError`, `reindex_all` |
| Факты пишутся только через `remember` | Сказанное в разговоре не попадает в память | Не закрыт; ADR-015 |
| Синхронный поиск внутри async-хода | Event loop стоит на время поиска | Ход, критик, воркер и tools памяти зовут память через `asyncio.to_thread` (SAM-74); голосовой путь - ADR-010 |

## Последствия

| Обязывает | Что даёт |
|---|---|
| Текст факта читается только из Mongo | Правка факта видна сразу, без переиндексации |
| Запись и удаление факта идут через `RAGStore` и `memory_repo` | Удаление не оставляет векторов-сирот |
| У факта есть вопросы-фасеты | Поиск по реальным вопросам человека |

| Запрещает или ограничивает | Чем платим |
|---|---|
| Верить тексту из payload Qdrant | Каждый найденный факт - лишний запрос в Mongo |
| Автоматическая переиндексация при `update` (только `reindex=True`) | Новые формулировки факта не ищутся до явной переиндексации |
| Change Streams | Qdrant догоняет Mongo только при обслуживании |
