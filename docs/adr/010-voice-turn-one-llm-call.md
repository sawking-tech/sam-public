# ADR-010: Голосовой ход - отдельный путь с одним вызовом LLM, проверки остаются у воркера

**Статус:** принято


## Контекст

Любая реплика идёт через `run_turn` (`gateway/runner.py:274`): guard (`runner.py:350`), `agent_loop`, критик
ответа до двух итераций (`runner.py:371-376`), повтор без tool (`runner.py:391-415`), повтор по глаголу
действия (`runner.py:418-440`). Это до пяти вызовов LLM подряд через семафор `LLM_CONCURRENCY` = 4
(`gateway/llm_client.py:29`). RAG синхронно держит event loop (`runner.py:314`). Ревью 8 окт называет эту
цепочку главным источником задержки; замера нет. Проверки появились по реальным сбоям моделей (SAM-07,
22a3b0f, 6d59182), поэтому просто выключить их нельзя.

## Решение

Голосовой ход получает свой эндпоинт `/voice/turn` (поток по WebSocket, ADR-012) и делает один вызов LLM.

| Проверка | На голосовом пути | В `run_turn` и у воркера |
|---|---|---|
| вызовы LLM | один, потоком | до пяти |
| guard, критик, повторы | нет | есть |
| tools | `spawn_agent` и `quiet` (тихий режим), у быстрой модели только `quiet` (`VOICE_TOOL_NAMES`, `FAST_TOOL_NAMES`, `gateway/voice_turn.py:32,35`) | полный набор роли |
| RAG | в потоке с общим сроком поиска (`gateway/recall.py`, `VOICE_RAG_TIMEOUT_S`, 1,5 с); не успел - ход без памяти | синхронно |
| MCP и `claude_delegate` | нет | у воркера |
| размышление модели | выключено или минимальный уровень (SAM-57) | по поставщику |

Сборка контекста общая (`build_messages`, `runner.py:170`). Текстовый `/v1/chat/completions` остаётся.

## Рассмотренные варианты

**Оставить `run_turn` и выключить критика флагом** (`response_critic_enabled`, `runner.py:224`). Отклонён:
guard и оба повтора остаются, вызовов три и больше. Теряем на выбранном пути: ничто не ловит ошибку модели
до звука.

**Параллелить проверки внутри `run_turn`.** Отклонён: вызовов столько же, локальная GPU делится между
ними. Сохранил бы все проверки - это и теряем.

**Один путь с флагом «голос / текст».** Отклонён: две логики в одной функции. Теряем на выбранном пути:
два пути надо держать согласованными.

## Риски и что с ними делаем

| Риск | Что происходит | Чем закрыт |
|---|---|---|
| Модель сказала «открыла», не вызвав `spawn_agent` | Обещание без действия | Основная модель видит ход и поправляет (ADR-014); механически не закрыт |
| RAG опоздал | Ответ без памяти | Строка в логе, доля таких ходов видна |
| Опасное действие без guard | - | На голосовом пути нет опасных tools; `HIGH_RISK_TOOLS` (`gateway/guard.py:33`) только у воркера |

## Последствия

| Обязывает | Что даёт |
|---|---|
| Голосовой ход делает ровно один вызов LLM; тест считает вызовы | Задержка до первого слова не растёт от новых проверок |
| Действие с голосового пути уходит только через `spawn_agent` | Guard и проверки действуют там, где действие выполняется |
| RAG на голосовом пути с таймаутом и вне event loop | Медленный поиск не останавливает ход и соседние сессии |
| Сборка контекста одна для обоих путей | Модель видит одинаковый контекст в голосе и в тексте |

| Запрещает или ограничивает | Чем платим |
|---|---|
| Guard, критик и повторы на голосовом пути | Ошибка модели звучит до поправки |
| MCP, `search_web`, `claude_delegate` на голосовом пути | Даже быстрое действие идёт через воркера и второй ход |
| Новая проверка в голосовой путь - только новым ADR | Улучшение качества ответа требует решения о задержке |
