# scenario

Сценарий автоматизации — то, ради чего SAM существует. Он говорит, за чем наблюдать, по какому признаку отличить
отклонение от нормы, что предвидеть, на что просигналить и чем снять причину. Задача от лёгкой, где хватает порога и
одного действия, до комплексной с несколькими агентами и памятью между ходами.

Оба вида собираются из одних и тех же частей и различаются тем, сколько работы отдано модели. Лёгкий: триггер
срабатывает всегда, условие вызова модели (`gate`) — код без LLM — решает, нужна ли модель, и только при непустом
ответе шаг зовёт основную модель. Комплексный: к этому добавляются агенты, память между ходами и живое приложение с
готовым результатом.

| Файл | Сценарий |
|---|---|
| [light.md](light.md) | порог и одно действие: `name`, `on.schedule`, `gate` на проверке свободного места, шаг `main_model` |
