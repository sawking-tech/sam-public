# Сценарий

Сценарий автоматизации — то, ради чего SAM существует. Он говорит, за чем наблюдать, по какому признаку отличить
отклонение от нормы, что предвидеть, на что просигналить и чем снять причину. Задача от лёгкой, где хватает порога и
одного действия, до комплексной с несколькими агентами и памятью между ходами.

| Файл | Содержимое |
|---|---|
| [light.md](light.md) | лёгкий сценарий: триггер, условие вызова модели без LLM, одно действие модели |
| [complex.md](complex.md) | комплексный сценарий: агенты, память между ходами, цепочка решений |

Готовые сценарии лежат в `workflows/` репозитория; как устроен файл сценария —
[workflows](../features/automation/workflows.md). Части, из которых сценарий собирается, —
[features](../features/README.md). Устройство внутри — [architecture](../architecture/README.md).
