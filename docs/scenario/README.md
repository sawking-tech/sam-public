# scenario

Ради чего SAM существует: сценарий автоматизации. Сценарий говорит, что наблюдать, как отличить отклонение от
нормы, что предвидеть, на что просигналить и чем снять причину.

| Файл | Что |
|---|---|
| [light.md](light.md) | лёгкий сценарий: порог, ворота без модели, одно действие |
| [complex.md](complex.md) | комплексный: несколько агентов, память между ходами, цепочка решений |

Части, из которых сценарий собирается, — [features](../features/README.md). Как они работают внутри —
[architecture](../architecture/README.md).
