# Комплексный сценарий

Несколько шагов работы, память между ними и цепочка решений. Собирается из тех же частей, что и лёгкий, но часть
работы отдаётся агентам.

Что добавляется по сравнению с лёгким:

| Потребность | Часть SAM |
|---|---|
| работа дольше одного вызова модели | агент: `spawn_agent` из хода, `claude_delegate` для кода, дерево агентов за ACP |
| решить, что делать дальше | шаг модели с инструментами; пул шагов на дерево не даёт агенту крутиться впустую |
| помнить прошлое в следующем ходе | факты памяти: запись `remember`, поиск на входе хода кладёт найденное в контекст |
| готовый результат, которым пользуются дальше | живое приложение: страница или сервис в своём контейнере |
| свой код посреди работы | песочница: контейнер на запуск без сети и данных стенда |

Пример: проверка и починка. Условия вызова модели находят сбойное. Шаг основной модели разбирает причину и ставит
агенту задачу.
Агент читает логи, ищет место в коде, правит, прогоняет тесты. Итог возвращается основной модели, та говорит
человеку и записывает факт в память, чтобы следующий такой сбой узнавать быстрее.
