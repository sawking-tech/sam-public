# operations

Что делать, когда SAM работает: смотреть состояние и понимать, что упало. Всё начинается с одной ручки: `GET /health`
отдаёт одной строкой, кто ведёт ход и что с блоками, каждая проверка не дольше `SAM_HEALTH_PROBE_TIMEOUT_S` (1 с).

Отказы различаются тем, кто их видит. Блок стенда виден строкой `components` и логом, его поднимает вкладка-надзиратель
через 3 с. Упавший шлюз целиком `/health` не отдаёт, его чинит внешний `scripts/stand_watch.py`. Молчащий надзор виден
строкой `stand_watch`, за него тревожит workflow `stand-silence`. Неработающая модель видна полем `main_model` и
правится `switch_main_model` без рестарта.
