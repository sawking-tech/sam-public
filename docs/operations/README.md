# operations

Расход денег и запуск. Устройство - в [architecture](../architecture/README.md), настройки фич - в
[features](../features/README.md).

**[cost.md](cost.md)** - деньги. `_token_usage` пишет каждый вызов с ролью и живёт 30 дней; цена берётся из
`prices.json` или от поставщика. `GET /sam/usage/cost` отдаёт сумму по валютам и разбивку; вызов без цены или
без usage в сумму не входит, но числится в `calls`. Тяжёлая работа ограничена рублями по скользящим окнам:
час 15 ₽, рабочее окно 5 ч - 40 ₽, сутки 150 ₽, месяц 3000 ₽. Задача сверх лимита ждёт в `_deferred_tasks`;
ступень `normal`/`saving`/`minimal`/`floor` понижается сразу, повышается после 30 минут выдержки.

**[install](../getting-started/install.md)** - запуск с нуля. Компоненты по отдельности и полный старт -
[README](../../README.md). Состояние стенда и надзор - [stand](../architecture/stand.md).
