| Файл | Что |
|---|---|
| [voice.md](voice.md) | вход: микрофон, эхоподавление, слух, опознание голоса, профили |
| [speech.md](speech.md) | выход: что звучит, синтез, очередь реплик, быстрая модель и поправка, перебивание |
| [addressee.md](addressee.md) | кому сказана фраза: что решает код до вызова модели, окно беседы |
