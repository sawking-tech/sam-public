# voice

SAM слышит и говорит. Слух идёт без слова-пробуждения: микрофон держит один узел звука, фразу закрывает тишина
`VOICE_SILENCE_SECS` (1,5 с) или 2,5 с после длинной речи. Говорящего опознаёт косинусная близость к профилю с порогом
`VOICE_MIN_SCORE` 0,4; опознание не считается аутентификацией. В разговоре две модели: быстрая отвечает первой,
основная проверяет и поправляет (ADR-014).

| Файл | Механизм |
|---|---|
| [voice.md](voice.md) | вход: узел звука и виртуальные микрофоны, эхоподавление, нарезка фраз, распознавание Whisper, опознание голоса и профили, что слух не делает |
| [speech.md](speech.md) | выход: что звучит (весь текст, кроме парных блоков меты, ADR-003), подготовка речи, очередь реплик, быстрая модель и поправка основной, перебивание |
| [addressee.md](addressee.md) | кому сказана фраза: что код решает до вызова модели, окно беседы, точность и набор правил |

Две детали, которые чаще всего спрашивают: озвучка идёт через узел звука, а не через динамики напрямую; фраза,
записанная голосом SAM, отбрасывается как эхо, а не уходит сама себе. Устройство стенда голоса —
[stand](../../architecture/stand/stand.md).
