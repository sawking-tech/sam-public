# Секрет команд

Опознание говорящего - не аутентификация: голос можно записать. Привилегированное действие подтверждается секретом
`SAM_COMMAND_SECRET` из `.env`, он произносится во фразе или пишется в чат монитора.

`gateway/secret_mask.py` (`mask`, `scrub`), `gateway/command_auth.py` (`secret_scope`), `gateway/guard.py`
(`guard_privileged`), `gateway/core_paths.py`.

## Секрет не идёт дальше входа

Слух (`voice/layer/hearing.py`), чат `/v1/chat/completions` и inject маскируют секрет и ставят признак `secret`:
список назначений названных ключей. Число, в котором секрет только содержится, маскируется, но командой не правит -
Whisper пишет число цифрами, с пробелами, словами, с тысячами, и все написания ловятся.

Ключей бывает несколько (SAM-104): каждый - переменная `SAM_<НАЗНАЧЕНИЕ>_SECRET` в `.env`, маскируются все,
привилегированные команды открывает только `command` (`SAM_COMMAND_SECRET`).

Последняя линия - стоки: `EventBus.emit` и `SessionRepo` прогоняют через `scrub` всё, что пишут в монитор и историю.
Монитор не показывает набранный текст сам, а ждёт его с маской от сервера.

## Как назначения доходят до гарда

ContextVar хода (`gateway/command_auth.py`, `secret_scope`): чат - вокруг хода, голос - мост передаёт поле, сокет
кладёт в задачу хода. `guard.guard_privileged` в цикле агента не выполняет без ключа инструменты
`SAM_PRIVILEGED_TOOLS`: `set_env`, `tune_self`, `forget`, `forget_topic`, `claude_delegate`, `switch_main_model`.
`mcp_call` судит основная модель, а не модель хода; сбой суда - блок. Отказ возвращается модели строкой «Нужен
ключ», она просит назвать его.

## Где ключ не нужен

`claude_delegate` требует ключ, только когда правит ядро (SAM-194, `gateway/core_paths.py`). Ядро - весь
репозиторий SAM, кроме папок `SAM_PERIPHERY_DIRS` (по умолчанию `data/apps`), и папка, которая содержит репозиторий
SAM. Папку приложения или другой репозиторий SAM правит без ключа: страховка - откат по истории git этого
репозитория, у приложения - по его собственной (задача apps-git-backup).
