# features

Что SAM умеет, как включается и какой порог за что отвечает. Устройство - в
[architecture](../architecture/index.md), деньги и запуск - в [operations](../operations/index.md).

**[workflows.md](workflows.md)** - проактивность без расписания в коде. Сценарий лежит файлом в `workflows/`,
повод - расписание или событие шины. Ворота без модели отсеивают почти всё, близкие поводы склеиваются в пачку;
замер 12 окт: 10 000 файлов дают 60-300 тыс. срабатываний в сутки при 5 тыс. за один тик.

**[guard.md](guard.md)** - что не выполнить. Правило `tool(шаблон) -> allow | ask | deny` решает по имени и
аргументам, паттерны ловят `rm -rf`, `DROP TABLE`, `curl | bash`, а спорное уходит судье на модели. Сбой судьи -
блок. Тут же пул шагов на дерево агентов и квота обращений по каналам.

**[sandbox.md](sandbox.md)** - исполнение кода от модели. Новый контейнер на запуск, без сети, секретов и данных
стенда; сеть выдаётся по запросу под файрволом. `sandbox_exec` держит тёплый контейнер беседы для проверок за
миллисекунды.

**[apps.md](apps.md)** - приложения, которые SAM делает сама. Живут в своём контейнере без выхода наружу, переживают
перезапуск Docker, показываются через шлюз с CSP sandbox по адресу `/apps/<slug>/`.

**[shell.md](shell.md)** - один каркас на все страницы: полоса с навигацией, колонка, выдвижная панель, тема.
Своё у страницы - только содержимое колонки. Раскладка и токены цвета взяты из `DotNetSolutionKit/site`.

**[memory-search.md](memory-search.md)** - поиск на входе каждого хода. Вектор в Qdrant и слова BM25 по Mongo
сливаются RRF (k=60); текст всегда из Mongo, поэтому архивный факт в выдачу не попадёт. Порог 0,5 режет только
вектор: факт со словом запроса находится и при слабом векторе.

**[voice.md](voice.md)** - вход голоса. Микрофон и колонки держит один процесс, речь SAM вычитается из микрофона
эхоподавлением. Слух работает без слова-пробуждения: фраза кончается по паузе 1,5 с, распознавание идёт кусками.
Профиль голоса ставит имя говорящему с порогом 0,4, свой голос - отдельный профиль.

**[speech.md](speech.md)** - выход голоса. Синтез идёт по предложениям, следующее готовится, пока звучит текущее;
в историю попадает только прозвучавшее. Перебить можно громкостью узнанным голосом или стоп-словом, перебитая
реплика договаривает до паузы между словами. Быстрая модель отвечает первой, основная поправляет, и каждая
поправка отодвигает быструю на 60 с, дальше вдвое, до 30 минут.

**[addressee.md](addressee.md)** - кому сказана фраза. Код решает ясное до вызова модели: эхо, свой голос, фон вне
беседы, обращение к питомцу. Остальное идёт модели с подсказкой, кто сказал и сколько прошло после реплики SAM.

**[character.md](character.md)** - поведение SAM. Один источник правил: короткие правила в промпте и скилл подачи
собираются из этого файла, а правится сначала он.

**[trace.md](trace.md)** - проверка ответов без живых людей: набор случаев «фраза и ожидание», прогон командой,
ходы в историю не пишутся. Трасса хода - этапы `context` и `first_token` в `_token_usage`.
