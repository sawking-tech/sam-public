# safety

Что SAM не выполнит. Проверок до исполнения четыре, и все четыре работают на одном вызове: политика по имени и
аргументам, паттерны опасных команд мгновенно, судья на модели с вердиктом `SAFE`/`UNSAFE`, проверка синтаксиса
ответа. Голосовой ход guard не проходит — у него один инструмент `spawn_agent`, проверки остаются в воркере (ADR-010).

| Файл | Механизм |
|---|---|
| [guard.md](guard.md) | правило `tool(шаблон аргументов) -> allow/ask/deny`, побеждает последнее подходящее; по умолчанию команды оболочки идут к судье, `set_env` запрещён, файл ключа привилегий запрещён в аргументах любого инструмента; паттерны `rm -rf`, `curl \| bash`, `DROP TABLE`; сбой судьи считается блоком; команды из списка только на чтение идут без судьи |

Защита цикла — тот же набор, что в [agent-loop](../../architecture/gateway/agent-loop.md): повтор вызова, опрос без
прогресса, лимит шагов. Два места, которые часто путают: guard решает, *исполнять ли* вызов инструмента, а секрет
команд ([command-secret](../../architecture/access/command-secret.md)) — *кто* имеет право на привилегированное
действие.
