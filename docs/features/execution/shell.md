# Каркас страниц

Один каркас на все страницы: монитор, страница приложений, радар, приложение в рамке. Полоса с навигацией, колонка
контента, выдвижная панель. Своё у страницы — только содержимое колонки и что лежит в панели.

Файлы в `gateway/static/shell/`. `shell.css`, `panel.js` и `boot.js` — копии из `DotNetSolutionKit/site` (cc7660d)
без правок: `panel.js` двигает рамку вместе с полосой, ширина из `--panelw` и `--maxw`, тема auto/light/dark,
сторона панели, выбор в `localStorage` под префиксом `sam`. `tests/test_shell.py` сверяет копии с источником, когда
репозиторий лежит рядом. Своё у SAM — `sam.css` (токены, шрифт, кнопка закрытия) и `shell.js` (рамка и API панелей).

## Раскладка

```
┌──────────── полоса .bar: прилипает сверху, высота --barh 53px ──────────────────────────────┐
│ [◆ SAM] Приложения Монитор Радар …  │  статус страницы  │  индикаторы [☾] [☰]    │
└─────────────────────────────────────────────────────────────────────────────────────────────┘
    ┌──────── колонка .wrap: до --maxw 1120px, по центру, поля --gut 20px ────────┐
    │  содержимое страницы                           │
    └────────────────────────────────────────────────────────────────────────────┘
                           ┌─ панель #sidebar --panelw 272px ─┐
                           │ выдвигается, сдвигает рамку   │
                           └──────────────────────────────────┘
```

- Полоса одна на всех страницах: слева лого (ведёт на домашний экран приложений) и навигация «Приложения» и
 закреплённые, по центру статус страницы, справа индикаторы, тема и кнопка панели.
- Колонка по центру, до 1120 px (1200 px от окна 1600 px). Образец даёт 920 px; шире, потому что ленте монитора
 нужна колонка телеметрии слева, а строку реплики держит `max-width: 80ch`. На 1440 px при открытой панели лист
 сдвигается на 112 px.
- До 900 px панель ложится поверх листа: сдвиг образца уводит страницу за край.
- Панели: слева, справа, обе, вкладки внутри (`SAMShell.openPanel({side, tab, title, ...})`). По умолчанию одна
 правая с вкладками: две открытые на 1440 px забирают 544 px.
- Граница колонки и панели — одна линия `--line` на всю высоту.

## Цвета

Палитра «ночной дом» (`gateway/static/shell/sam.css`) перекрывает токены образца (`--ground`, `--panel`, `--line`,
`--text`, `--muted`, `--focus`), копия `shell.css` не тронута.

| Токен | Что |
|---|---|
| `--r-ink` | фон, ночь |
| `--deck` | поверхности: колонка, панель, карточки; второй уровень — смесь `--deck` и `--wire` |
| `--wire` | линии и границы |
| `--haze` | вторичный текст, служебное, инструменты и воркеры |
| `--r-text` | текст |
| `--amber` | человек в разговоре, фокус |
| `--ice` | SAM, «сейчас», живая связь, идёт ход |
| `--lilac` | голос и мысль SAM (на радаре — `--pet`) |
| `--alarm` | ошибка, обрыв, STOP |

Светлая тема «дом днём»: те же имена, бумага, чернила, акценты темнее в OKLCH до 4.5:1, свечение `--glow` только у
живых точек.

## Подключение

```html
<link rel="stylesheet" href="G/static/shell/shell.css"><link rel="stylesheet" href="G/static/shell/sam.css">
<script src="G/shell/config.js"></script><script src="G/static/shell/boot.js"></script>
<script src="G/static/shell/shell.js" defer data-page="apps"></script>
```

`G` — адрес шлюза, у страниц шлюза пусто. `boot.js` ставит тему до первой отрисовки, `shell.js` переносит
содержимое в рамку (`#sam-content`) и подгружает `panel.js`. Навигацию отдаёт `/shell/config.js`
(`gateway/shell_config.py`: приложения, монитор, радар, если поставлен). Страница на другом порту (радар `:8010`)
подключает каркас со шлюза.

| Атрибут тега `shell.js` | Что делает |
|---|---|
| `data-page` | ключ страницы: навигация отмечает её текущей |
| `data-shell="off"` | без каркаса, своя полноэкранная страница; API панелей ничего не делает |
| `data-bar="off"` | без полосы |
| `data-panelw="360"` | ширина панели, px |
| `data-maxw="4000"` | ширина колонки, px; шире окна — панель всегда выдвижная |
| `data-fill="1"` | контент занимает окно под полосой, прокрутка внутри страницы (монитор) |

## API панелей

`window.SAMShell`:

- `openPanel({title, node | src | srcdoc | tabs, tab, side, onClose})` — панель с содержимым: узел страницы, адрес,
 разметка или вкладки `[{key, title, node}]` во фрейме с `sandbox="allow-scripts"`. Одна панель за раз.
- `closePanel` — закрыть, фокус возвращается на прежнее место; закрывают Esc и кнопка в шапке.
- `setDefaultPanel(title, node | tabs)` — что панель показывает без вызова; по умолчанию список страниц SAM.
- `setStatus(node | text)`, `setTools(...nodes)`, `setBusy(bool)`, `setVoice(bool)` — статус в центре полосы,
 индикаторы справа, скан-луч хода, эквалайзер голоса.
- `connectApp(iframe, slug)` — принимать вызовы панелей от приложения в этом фрейме.

На широком экране панель стоит в поле сбоку всегда (так устроен `panel.js`); вызов меняет содержимое, закрытие
возвращает содержимое по умолчанию.

## Монитор

```
┌─ полоса ─────────────────────────────────────────────────────────────────────────────────────┐
│ [◆ SAM] Приложения Монитор Радар │ ведёт: llm, сжатие voice: 23 без сжатия, 31 мин назад │ ● 290 [⛔ STOP] [☾] [☰] │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
  ┌─ колонка ──────────────────────────────────────────────────────────────────┐
  │  ↑ старые сообщения подгружаются при прокрутке вверх            │
  │  последние сообщения — сразу, внизу                    │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │  [ поле ввода                       ] [Отправить]  │
  └─────────────────────────────────────────────────────────────────────────────┘
  панель (кнопка ☰ или кнопки полосы): Задачи | Настройки | Фильтр событий
```

- Последние сообщения — сразу внизу, старые подгружаются вверх. Шлюз шлёт первой порцией последние
 `SAM_MONITOR_FIRST_PAGE` (60) событий. Последние 80 событий вкладка держит в `sessionStorage` 10 минут: после F5
 они встают уже внизу, снимок дописывает новое по `ts_iso` (проверено 15 окт: 55 строк из кеша, 55 после снимка,
 145 после прокрутки).
- Новое событие дописывается в конец, список не перерисовывается: перерисовка сбивает прокрутку.
- Порция истории кончается на записи с временем и `_id`, следующая начинается строго раньше: записи одной
 миллисекунды границу не теряют. Индексы (`timestamp`, `_id`) и (`session_id`, `timestamp`, `_id`) у `sam.sessions`
 и `created_at` у `sam.tasks` шлюз создаёт при старте.
- Статус по центру полосы: кто ведёт, сжатие. Индикаторы и STOP справа.
- Задачи и настройки — в панели. Список задач после F5 берётся из `GET /sam/tasks`: события `task_*` в историю не
 пишутся.
- Селектор внизу выбирает ленту и адресата реплики; «все сессии» — реплика уходит в `homepc`. Выбор адресата
 переживает F5 (`localStorage`), агент как адресат не восстанавливается. «Глаз» задачи открывает ленту агента;
 у закончившегося агента у поля ввода — «фраза оживит агента <имя>». Записи выбранной сессии старше общей ленты
 подгружаются её курсором (`/sam/monitor/history?session=`).
- `guard_check` и `guard_pass` дают пометку `guard ✓` у строки вызова (по сессии и `call_id`), отдельной строкой
 идёт только `guard_block`. У вызова из текста (`text_<шаг>_<номер>`) проверка приходит раньше: пометка ждёт его не
 дольше минуты. Длинные аргументы показаны началом, щелчок разворачивает. Итог вызова — до
 `SAM_MONITOR_RESULT_CHARS` (4000) знаков.

Монитор — `gateway/static/monitor.html`, модули — `gateway/static/monitor/`. Лента монитора — `#mon`, рамка
каркаса — `#main`; цвета `--m-text` и `--m-muted` — псевдонимы токенов. Логика разбора проверяется в
`tests/js/monitor` (node --test через `tests/test_monitor_modules.py`).

```
    │ Закреплённые                               │
    │ [▣ Монитор] [◎ Радар] [▦ График]                     │

    │ [▦ Доска] [▤ Тренажёр]                          │
    └─────────────────────────────────────────────────────────────────────────────┘
  плитка: лого SVG или скриншот, имя, точка состояния; на углу ⏸/▶ и ⚙

```

Приостановить — на плитке, остальное в панели. Устройство приложений — [apps.md](apps.md).

## Радар и приложение в рамке

- Радар (`radar/static/presence.html`, сервис `:8010`) — карта дома шире колонки: переопределяет ширину, полоса и
 панель общие. Сцена на всё окно под стеклом полосы, подписи и отладка встают под полосу (класс `sam-shell`), свои
 цвета `--r-ink` и `--r-text`. Копия каркаса радару не нужна: без шлюза страница всё равно не работает.
- Приложение — страница во фрейме на всю колонку: `/apps/<slug>` (`gateway/app_view.py`). Поле `shell` манифеста
 переопределяет только атрибуты тега `shell.js`; имя и просьба подставляются текстом с экранированием. `/apps/<id>`
 отвечает 308 на `/apps/<slug>`, `/apps/radar` — 307 на радар.

Панели приложение вызывает клиентом `/static/shell/app-client.js`: `SAMApp.openPanel({title, path})` — своя страница
по пути внутри приложения, `SAMApp.openPanel({title, html})` — разметка, `SAMApp.closePanel`. `bridge.js` принимает
сообщение, только если источник — окно фрейма этого приложения и origin `null` (песочница CSP) или шлюза; путь
относительный, без схемы и `..`. Разметка приложения в DOM каркаса не попадает.

## Проверка

`tests/test_shell.py` (копии с образцом, атрибуты, API панелей), `tests/test_monitor_modules.py` и `tests/js/monitor`,
`tests/integration/test_live_surface.py`. Снимки на 375, 768 и 1440 px в обеих темах: полоса и колонка совпадают по
положению, линии сплошные, консоль без ошибок.
