# money

Сколько SAM стоит и когда останавливается. Считают два места: `_token_usage` пишет каждый вызов LLM с ролью, цена
берётся из `gateway/prices.json`, лимиты `SAM_DEV_*` режут расход по скользящим окнам — час, рабочее окно, сутки,
неделя, месяц. Вызов без цены или без usage в сумму не входит, но числится в `calls`: неполный итог не выдаётся за
полный.

| Файл | Механизм |
|---|---|
| [cost.md](cost.md) | роли вызовов (`main`, `worker`, `guard`, `judge`, `summarize`, `workflow`, `unknown`), таблица цен по `поставщик/модель`, `GET /sam/usage/cost` с разбивкой по роли, модели, источнику и дню, остатки поставщиков, лимиты в рублях, очередь отложенных задач и ступени |

Тяжёлая задача — та, что заказала шагов больше `SAM_LIGHT_TASK_STEPS` (10); при исчерпанном лимите она встаёт в
`_deferred_tasks` и запускается сама, когда окно откроется. Пул шагов считается в
[worker](../../architecture/agents/worker.md).
