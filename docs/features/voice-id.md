# Опознание голоса

Каждая фраза и каждый кусок фразы получают имя профиля, чей голос ближе, и оценку близости. Имя доходит до шлюза
полем `who` и решает, кому сказана фраза (`addressee.md`), кто может перебить SAM громкостью (`barge-in.md`) и что
считать эхом (`hearing.md`). Почему так - ADR-011. Опознание голоса - не аутентификация: привилегированные
команды требуют ключа (`gateway/secret_mask.py`).

`voice/layer/speakers.py` (SAM-30).

## Как

| Что | Значение |
|---|---|
| модель | ECAPA `speechbrain/spkrec-ecapa-voxceleb` на CPU; кэш модели - `SAM_VOICES_DIR/.model` |
| профиль | средний нормированный эмбеддинг записей человека, `SAM_VOICES_DIR/<имя>.npy` (по умолчанию `data/voice/voices`, вне git) |
| оценка | косинусная близость эмбеддинга фразы к каждому профилю; берётся лучший |
| порог | `VOICE_MIN_SCORE` 0,4: ниже - «неизвестно» (`who: null`), оценка всё равно пишется |
| короткий звук | меньше 0,5 с - не опознаётся |
| свой голос | профиль `SAM_SELF_PROFILE` (по умолчанию `claude`): фраза этим голосом - эхо озвучки SAM, кусок с ним в шину не пишется |
| битый профиль | недописанный файл, не вектор или профиль другой модели эмбеддингов пропускается, о нём одна строка за запуск; остальные опознаются |

Порог 0,4: на 1392 фразах 8 окт (`python -m voice.layer.speaker_eval score|report`) на 0,4 «неизвестно» 276 фраз,
из них длиннее 6 с - 21, чужой профиль побеждает в 2; на 0,35 «неизвестно» 207, чужой - 5.

Опознание идёт в отдельном потоке параллельно распознаванию. Нет speechbrain или профилей - слух работает без
поля `who` и пишет об этом одну строку; громкостью тогда перебивает любой звук громче порога.

## Профили

```
python -m voice.layer.speakers enroll <имя> <файл.wav> [...]   профиль из записей
python -m voice.layer.speakers enroll-claude                   свой профиль из пяти фраз синтеза голосом по умолчанию
python -m voice.layer.speakers who <файл.wav>                  кто на записи
python -m voice.layer.speakers list
```

Профиль своего голоса снимается заново после смены голоса синтеза.

## Проверка

`tests/test_speakers_recordings.py` - размеченные фразы от 3 с из `data/voice/eval` (без набора тест пропускается).

## Не закрыто

- Гость без профиля не опознаётся: громкостью он перебивает SAM, только если звук громче `VOICE_BARGE_RMS_SURE`.
- В одной фразе могут говорить двое: у фразы одно имя; куски по ходу речи опознаются каждый своим голосом.
- Крик опознаётся хуже речи: 8 окт на крике за 1 с оценка 0,11-0,28.
