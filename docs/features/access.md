# Доступ к шлюзу

Шлюз (`:8000`) и агрегатор MCP (`:3000`) слушают `0.0.0.0`. Ключ `SAM_API_KEY` из `.env` пускает с любой машины;
ключа нет - пускаются только запросы с этой (`SAM_LOCAL_HOSTS`: по умолчанию `127.0.0.1`, `::1`, `localhost`),
на старте строка в логе.

`gateway/access.py` - ASGI-слой на HTTP и WebSocket, `gateway/privilege_key.py` - второй ключ,
`gateway/tool_policy.json` - запрет на файл ключа в аргументах.

## Два ключа

| Ключ | Где лежит | Что открывает | Кто шлёт |
|---|---|---|---|
| `SAM_API_KEY` | `.env` | вход в шлюз и агрегатор с чужой машины | клиенты заголовком `X-SAM-Key` или `Authorization: Bearer`: шлюз в агрегатор, `voice_client.py`, `client_agent.py`, `chat.py`, мост |
| `X-SAM-Privilege` | файл `data/secrets/privilege.key` (`SAM_PRIVILEGE_FILE`) | создать агента, выдать права, сменить модель | MCP `sam` ведущего |

Ключ привилегий нужен даже с этой машины и только четырём ручкам: `POST /sam/agents`, `/sam/agents/{id}/grant`,
`/sam/main-model`, `/sam/llm/switch`. Без него агент с командой оболочки создал бы агента мимо своих прав (SAM-177).
В `.env` и окружении ключа нет; файла нет - шлюз создаёт его при первом обращении. Политика запрещает называть
этот файл в аргументах любого инструмента: иначе агент прочёл бы ключ и обошёл выдачу.

## Что закрыто без ключа

- **Host.** Пускается только имя этой машины (её адреса и имя, `localhost`, `host.docker.internal`, добавочные -
  `SAM_ALLOWED_HOSTS`); чужое - 403. Короткое имя сети вроде `gateway` из compose соседний хост может
  перепривязать через LLMNR, иначе страница чужого имени, перепривязанного на `127.0.0.1` (DNS rebinding),
  становилась своей.
- **Origin.** WebSocket браузер открывает с любой страницы без CORS, поэтому рукопожатие с заголовком `Origin`
  пускается только со своей страницы (тот же Host) или из `SAM_ALLOWED_ORIGINS`. Клиенты на Python Origin не шлют.
- **`Content-Type`.** POST принимается только `application/json`, иначе 415 (SAM-188). Иначе любая страница в
  браузере простым POST (`text/plain`, форма, без тела, без preflight CORS) звала `run_command` агрегатора:
  заголовок JSON браузер ставит чужой странице только после preflight, а его сервер не разрешает. Прокси живых
  приложений `/apps/<id>/` из правила исключён - тело идёт в контейнер приложения.
- **Метод.** Ручка, меняющая состояние, не GET: `GET` зовёт любая страница картинкой.

## Монитор

`/monitor?key=<ключ>` открывается один раз, дальше cookie. `/health` открыт всегда. Шлюз и агрегатор на разных
машинах работают только с заданным ключом.
