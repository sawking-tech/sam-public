# checks

Проверка без живых людей. Случай — фраза и ожидание, которое проверяет код: вызван ли `spawn_agent`, был ответ или
молчание, нет ли обещания действия без вызова. Набор собирается из истории командой `export`, прогон идёт без записи
в историю.

| Файл | Механизм |
|---|---|
| [trace.md](trace.md) | `scripts/eval_voice.py export` и `run` на наборе случаев, итог с медианой и максимумом задержки; трасса хода — этапы `history`, `rag`, `route`, `context`, `first_token` в миллисекундах в поле `stages` записи `_token_usage` |

Трассу сейчас ведёт голосовой ход (`gateway/voice_turn.py`); обычный ход шлюза пишет только `first_token`, если ответ
шёл стримом. Учёт токенов по ролям — [cost](../money/cost.md).
