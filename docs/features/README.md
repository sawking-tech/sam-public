# Как работают фичи SAM

Справка по устройству: правила, пороги, переменные, файлы. Почему так решено - `docs/adr/`. Основная модель
читает эти файлы, когда ей не хватает знания о своей среде.

| Файл | Что |
|---|---|
| [stand](stand.md) | блоки стенда: где, зачем, что есть, если упал; кто что поднимает |
| [main-model](main-model.md) | основная модель: конкретные модели, приоритет, Claude Code носителем |
| [prompt](prompt.md) | системный промпт: душа, инструкции, личный слой; правка и откат |
| [character](character.md) | характер и подача: когда делает сама, когда спорит, порядок ответа, лестница, тон |
| [access](access.md) | доступ к шлюзу: ключ API, ключ привилегий, Host, Origin, Content-Type |
| [command-secret](command-secret.md) | секрет команд: где звучит, как маскируется, что без него не выполняется |
| [addressee](addressee.md) | кому сказана фраза: правила кода, окно беседы, набор и точность |
| [session-queue](session-queue.md) | очередь фраз сессии и управление ею |
| [speech-text](speech-text.md) | что не звучит (мета-блоки в парных тегах), звенья подготовки речи, что не закрыто |
| [memory-in-pauses](memory-in-pauses.md) | ворота простоя, пороги сжатия, извлечение фактов |
| [compression](compression.md) | сжатие истории: окно в токенах, шаги прохода, архив |

| [llm-router](llm-router.md) | выбор модели по виду задачи, цепочки, отказы поставщиков |

| [speech-out](speech-out.md) | синтез и очередь реплик: кто звучит, отрезки, судьба реплик, голос и движок |
| [fast-voice](fast-voice.md) | быстрый голос: кто отвечает на фразу, проверка и поправка основной, откат, при ведущем |

| [sandbox](sandbox.md) | песочница: изоляция, сеть по запросу, пакеты, файлы внутрь и наружу, быстрая песочница, настройки |
