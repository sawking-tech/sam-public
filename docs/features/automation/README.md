# automation

Работа без реплики человека. Проактивность держится на трёх понятиях, и путать их нельзя: **триггер** решает, когда
сценарий срабатывает, и срабатывает всегда; **условие вызова модели** (`gate`) — код или shell, который после
срабатывания решает, нужна ли модель вообще; **шаг** — то, что модель делает, если её позвали. Порог и одно действие
укладываются в дешёвый сценарий без LLM на отсеве, комплексный отдаёт работу агентам.

| Файл | Механизм |
|---|---|
| [workflows.md](workflows.md) | workflow файлом в `workflows/*.yml`: расписание `on.schedule` или событие шины `on.event`, условие вызова модели кодом без модели (пустой ответ — модель не зовётся, тот же ответ, что в прошлый раз, тоже), шаги `main_model` и `tool`, категории и метки, очередь push с подтверждением |

Файл вместо n8n и вместо крона сессии — потому что сценарий должен лежать в репозитории рядом с кодом, а не в чужой
базе; причины — [ADR-020](../../adr/020-light-stand-workflows.md). Кому отдаётся вход —
[main-model](../../architecture/gateway/main-model.md). Как собрать готовый сценарий — [scenario](../../scenario/README.md).
