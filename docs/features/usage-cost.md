# Расходы на LLM: сколько стоит SAM

`GET /sam/usage/cost?days=7&group_by=role` отвечает, сколько стоили вызовы LLM за период и сколько осталось у поставщиков.

## Откуда цифры

- Токены каждого вызова пишет `gateway/token_usage.py` в коллекцию `_token_usage` (SAM-48); записи живут `SAM_TOKEN_USAGE_TTL_DAYS` (30) дней, дальше период ответа не растянуть.
- Цена за 1M токенов лежит в `gateway/prices.json`, свою таблицу задаёт `SAM_PRICES_FILE`. Ключ строки: `поставщик/модель`, а `lmstudio/*` - все модели поставщика. Валюта у каждой строки своя, суммы по валютам не смешиваются.
- Если поставщик сам присылает стоимость вызова в `usage.cost`, запись вызова хранит её как есть (поле `cost`), без привязки к поставщику. Валюту источника объявляет секция `cost_currency` в `prices.json` (сейчас `openrouter`: USD): при суммировании стоимость берётся у источника с объявленной валютой, остальные считаются по `prices`. Новому поставщику хватает строки в `cost_currency`, код не меняется.
- Кэшированные токены входят во вход и считаются по `cached_input`; у строки без него - по цене входа.
- Остаток: у OpenRouter `GET /credits` (всего пополнено минус израсходовано) и `GET /key` (лимит и остаток ключа SAM). У z.ai по подписке и у polza.ai остатка в ответе нет.

## Что в ответе

`cost` - сумма и разбивка по `group_by` (`role`, `model`, `source`, `day`) отдельно по валютам; `calls` - сколько вызовов всего, учтено в сумме (`priced`, из них `provider_cost` со стоимостью от поставщика), без usage (поставщик не вернул токены) и без цены; `unpriced_models` - у каких моделей нет строки в таблице; `balances` - остатки.

Вызов без цены или без usage в сумму не входит, но числится в `calls`: неполный итог не выдаётся за полный. Цену модели, которой нет в таблице, добавляют строкой в `prices.json`.

## Где код

`gateway/pricing.py` (цена и стоимость вызова), `gateway/usage_cost.py` (сводка), `gateway/balance.py` (остатки), `TokenUsageRepo.rows_since`, эндпоинт в `gateway/main.py`; тесты - `tests/test_usage_cost.py`.
