# memory

Что SAM помнит и как находит. Разделение одно и держится везде: **MongoDB хранит правду, Qdrant — оглавление**.
Факт — это документ с полным текстом, summary и вопросами, на которые он отвечает; в Qdrant лежит по вектору на
summary и на каждый вопрос. Поэтому Qdrant пересоздаётся без потери данных, а текст в ответе всегда из Mongo
(ADR-009).

| Файл | Механизм |
|---|---|
| [memory-search.md](memory-search.md) | запись факта с проверкой на дубль по косинусу 0,92, гибридный поиск: вектор с порогом 0,5, BM25 по словам, слияние RRF, текст из Mongo; эмбеддер `paraphrase-multilingual-MiniLM-L12-v2` отдельным процессом |
| [household.md](household.md) | состав дома: люди с ролью и питомцы, анкета в мониторе или `set_household_member`, блок «ДОМ» в промпте, кэш 60 с, клички для питомцев |

Код ищет память на входе хода, а не модель: найденное приходит в контекст до выбора основной модели со сроком
`VOICE_RAG_TIMEOUT_S` (1,5 с). Когда факты пишутся сами и когда идёт обслуживание —
[compression](../../architecture/context/compression.md).
