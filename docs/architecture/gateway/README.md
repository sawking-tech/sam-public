# gateway

Входы шлюза и то, что они делают с ходом: кто ведёт ход, как идёт цикл, из чего собирается промпт, каким форматом
модель вызывает инструмент.

| Файл | Что |
|---|---|
| [main-model.md](main-model.md) | кто ведёт ход: модель внутри шлюза или сессия Claude Code; приоритет, инерция, смена без рестарта |
| [agent-loop.md](agent-loop.md) | один цикл «модель — вызовы — результаты» для всех ролей; защита от петель; очередь фраз сессии |
| [prompt.md](prompt.md) | сборка системного промпта из души, инструкций и личного слоя |
| [tool-formats.md](tool-formats.md) | как модель пишет вызов инструмента и как шлюз разбирает его из текста |
