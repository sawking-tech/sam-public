# architecture

Как SAM устроена изнутри. Устройство не зависит от настроек; что включается и настраивается - в
[features](../features/index.md), запуск и деньги - в [operations](../operations/index.md).

**[stand.md](stand.md)** - стенд держит каждый компонент живым сам: вкладка-надзиратель поднимает упавший через
3 с, мост и сессию Claude Code поднимает следующий запуск, надзор поднимает лежащий шлюз. Упавшее по сигналу
надзора чинит модель без вопроса.

**[main-model.md](main-model.md)** - вход отдаётся основной модели по приоритету `SAM_MAIN_MODELS` (по умолчанию
`claude-code,llm`). Текущая модель остаётся, пока доступна; ведущий без `lead.alive` моложе 5 с считается мёртвым,
и ход берёт следующая. Смена без рестарта - `POST /sam/main-model`.

**[llm-router.md](llm-router.md)** - вид задачи выбирает цепочку поставщиков: `fast` для голоса, `turn` для
текста, `planning` для структурированного JSON, `default` для остального. Отказ ставит поставщика на паузу по
типу: 429 - 2-20 с растущей, ключ - час, 5xx - 10 с; вызов уходит следующему.

**[tool-formats.md](tool-formats.md)** - вызов инструмента пишется по-разному: harmony специальными токенами,
qwen тегом `<tool_call>`, остальные нативно. Формат определяется по имени модели; вызов, пришедший текстом,
разбирается тем же слоем, поэтому модель без нативного протокола инструменты всё равно вызывает.

**[agent-loop.md](agent-loop.md)** - главный агент, воркер и агент Cortex идут одним циклом «модель - вызовы -
результаты». Три одинаковых вызова подряд дают подсказку, пять - принудительный ответ без инструментов; повтор с
теми же аргументами не исполняется. Очередь фраз сессии: пока идёт ход, новые фразы копятся и уходят одним
сообщением после.

**[workers.md](workers.md)** - воркер живёт в отдельной сессии `task:<id>`, по умолчанию 300 с на задачу и пул
шагов на дерево (`SAM_AGENT_STEPS`, 30, не больше 100). Итог возвращает `report_status("ОТВЕТ: ...")`, который
заканчивает работу. Закрытый воркер остаётся idle-сессией и оживает по `send_to_agent`.

**[agents.md](agents.md)** - агент за ACP работает подпроцессом, свой агент SAM - Cortex. Права выдаёт создатель:
подмножество инструментов, метка сложности, глубина детей. Создателю можно задать вопрос, доложить и попросить
шагов; неистраченное закрытой задачи возвращается родителю.

**[prompt.md](prompt.md)** - промпт собирается из трёх слоёв. Душа (характер) живёт в Mongo `_soul` и правится без
рестарта, инструкции - в `SAM.md` и читаются раз на процесс, личный слой - в `data/SAM.md` и читается на каждой
сборке. У души история версий и откат; правка принимается только поверх версии, которую автор видел.

**[compression.md](compression.md)** - контекст постоянного размера: сводок в контексте не больше
`SAM_COMPRESS_SUMMARY_CEILING` (4), плюс несжатое окно около 600 токенов. Когда сводок больше, соседние сливаются
попарно, начиная со старых, поэтому самая старая сводка накапливает всю раннюю беседу.

**[storage.md](storage.md)** - MongoDB - источник правды, Qdrant - только оглавление к фактам; текст всегда
читается из Mongo, а Qdrant можно пересоздать без потери данных. У `tasks` TTL по статусу (done 24 ч, failed 2 ч),
у `_token_usage` - 30 дней.

**[access.md](access.md)** - без `SAM_API_KEY` шлюз пускает только с этой машины. POST принимается лишь с
`application/json` (иначе 415): иначе любая страница в браузере простым POST звала `run_command` агрегатора.
Ручки агентов и смены модели требуют второй ключ `X-SAM-Privilege` даже с этой машины.

**[command-secret.md](command-secret.md)** - опознание голоса не аутентификация, поэтому привилегированное
действие подтверждается секретом из `.env`. Секрет маскируется на входе и до модели не доходит; без него
`set_env`, `tune_self`, `forget`, `claude_delegate` и смена модели не выполняются.

Разделение ролей и то, куда система идёт, - [brain-map](../brain-map.md).
