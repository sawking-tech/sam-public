# Доступ к шлюзу

Шлюз на `:8000` и агрегатор MCP на `:3000` слушают `0.0.0.0`. Ключ `SAM_API_KEY` из `.env` пускает с любой машины.
Без ключа пускаются только запросы с этой машины: `SAM_LOCAL_HOSTS` по умолчанию содержит `127.0.0.1`, `::1` и
`localhost`, на старте об этом строка в логе.

Код: `gateway/access.py` — ASGI-слой на HTTP и WebSocket, `gateway/privilege_key.py` — ключ привилегий,
`gateway/tool_policy.json` — запрет на файл ключа в аргументах инструмента.

## Два ключа

| Ключ | Место | Открывает | Кто шлёт |
|---|---|---|---|
| `SAM_API_KEY` | `.env` | вход в шлюз и агрегатор с чужой машины | клиенты заголовком `X-SAM-Key` или `Authorization: Bearer`: шлюз в агрегатор, `voice_client.py`, `client_agent.py`, `chat.py`, мост |
| `X-SAM-Privilege` | `data/secrets/privilege.key`, путь меняет `SAM_PRIVILEGE_FILE` | создание агента, выдача прав, смена модели | MCP `sam` ведущего |

Ключ привилегий требуется даже с этой машины, и только четырём ручкам: `POST /sam/agents`,
`POST /sam/agents/{id}/grant`, `POST /sam/main-model`, `POST /sam/llm/switch`. Без него агент с командой оболочки
создал бы агента мимо своих прав. В `.env` и окружении ключа нет. Файла нет — шлюз создаёт его при первом
обращении. Политика запрещает называть этот файл в аргументах любого инструмента, иначе агент прочёл бы ключ и
обошёл выдачу.

## Проверки без ключа

`Host`. Пускается только имя этой машины: её адреса и имя, `localhost`, `host.docker.internal`, добавочные имена
из `SAM_ALLOWED_HOSTS`. Чужое имя получает 403. Короткое имя сети вроде `gateway` из compose соседний хост может
перепривязать через LLMNR, и без этой проверки страница чужого имени, перепривязанного на `127.0.0.1` (DNS
rebinding), становилась своей.

`Origin`. WebSocket браузер открывает с любой страницы без CORS, поэтому рукопожатие с заголовком `Origin`
пускается только со своей страницы (тот же Host) или из `SAM_ALLOWED_ORIGINS`. Клиенты на Python заголовок
`Origin` не шлют.

`Content-Type`. POST принимается только с `application/json`, иначе 415. Без этого любая страница в браузере
простым POST (`text/plain`, форма, без тела, без preflight CORS) звала `run_command` агрегатора: заголовок JSON
браузер ставит чужой странице только после preflight, а его сервер не разрешает. Прокси живых приложений
`/apps/<id>/` из правила исключён: тело идёт в контейнер приложения.

`Метод`. Ручка, меняющая состояние, не отвечает на GET: GET зовёт любая страница картинкой.

## Монитор

`/monitor?key=<ключ>` открывается один раз, дальше доступ по cookie. `/health` открыт всегда. Шлюз и агрегатор на
разных машинах работают только с заданным ключом.
