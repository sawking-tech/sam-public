# Секрет команд

Опознание говорящего не служит аутентификацией: голос можно записать. Привилегированное действие подтверждается
секретом `SAM_COMMAND_SECRET` из `.env`; секрет произносят во фразе или пишут в чат монитора.

Код: `gateway/secret_mask.py` (`mask`, `scrub`), `gateway/command_auth.py` (`secret_scope`), `gateway/guard.py`
(`guard_privileged`), `gateway/core_paths.py`.

## Маскировка на входе

Слух (`voice/layer/hearing.py`), чат `/v1/chat/completions` и inject маскируют секрет и ставят признак `secret` со
списком назначений названных ключей. Число, в котором секрет только содержится, маскируется, но командой не
считается: Whisper пишет число цифрами, с пробелами, словами и с тысячами, и все написания ловятся.

Ключей бывает несколько. Каждый — переменная `SAM_<НАЗНАЧЕНИЕ>_SECRET` в `.env`; маскируются все, а
привилегированные команды открывает только `command` (`SAM_COMMAND_SECRET`).

Последняя линия — стоки: `EventBus.emit` и `SessionRepo` прогоняют через `scrub` всё, что пишут в монитор и
историю. Монитор не показывает набранный текст сам, а ждёт его с маской от сервера.

## Путь назначения до гарда

Назначения хода живут в ContextVar (`gateway/command_auth.py`, `secret_scope`): в чате — вокруг хода, в голосе —
мост передаёт поле, сокет кладёт его в задачу хода. `guard.guard_privileged` в цикле агента не выполняет без ключа
инструменты из `SAM_PRIVILEGED_TOOLS`: `set_env`, `tune_self`, `forget`, `forget_topic`, `claude_delegate`,
`switch_main_model`. `mcp_call` судит основная модель, а не модель хода; сбой суда считается блоком. Отказ
возвращается модели строкой «Нужен ключ», и она просит назвать его.

## Места без ключа

`claude_delegate` требует ключ только тогда, когда правит ядро (`gateway/core_paths.py`). Ядро — весь репозиторий
SAM, кроме папок из `SAM_PERIPHERY_DIRS` (по умолчанию `data/apps`), и папка, содержащая репозиторий SAM. Папку
приложения или другой репозиторий SAM `claude_delegate` правит без ключа: страховка — откат по истории git этого
репозитория, у приложения — по его собственной.
