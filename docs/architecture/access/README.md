# Доступ

Кто попадает в шлюз и что требует подтверждения. Два ключа с разными задачами: `SAM_API_KEY` пускает в шлюз с
чужой машины, ключ привилегий открывает четыре ручки, меняющие власть агентов. Без обоих шлюз работает только с
этой машины. Секрет команд — третий механизм: он подтверждает конкретное привилегированное действие в разговоре.

| Файл | Механизм |
|---|---|
| [access.md](access.md) | `SAM_API_KEY` против ключа привилегий, проверки без ключа: `Host` против DNS rebinding, `Origin` для WebSocket, `Content-Type` против простого POST с чужой страницы, запрет GET на изменяющие ручки |
| [command-secret.md](command-secret.md) | секрет команд `SAM_COMMAND_SECRET`: маскировка на входе в слухе и чате, признак `secret` с назначением ключа, ContextVar `secret_scope` до гарда, место `claude_delegate` без ключа |

Опознание говорящего входом не считается: голос можно записать. Что защищает инструменты модели —
[guard](../../features/safety/guard.md).
