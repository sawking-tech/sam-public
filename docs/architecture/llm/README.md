# Выбор модели

Какую модель берёт каждый вызов. Устройство одно: вызов называет **вид задачи**, роутер по нему выбирает поставщика и
идёт по цепочке запасных, клиент помнит отказы и ставит поставщика на паузу. Агенту модель подбирается отдельной
функцией по цене и вероятности успеха на таких задачах.

| Файл | Механизм |
|---|---|
| [llm-router.md](llm-router.md) | виды задач `fast`/`turn`/`planning`/`default` и их цепочки; подбор модели агенту (p успеха из `_task_runs`, цена с учётом повторов, доля бюджета, ранжирование с запасными); уровень рассуждения по роли вызова; классификация отказов и паузы 2-5-10-20 с, час при 403 |

Две развилки, которые часто путают: `LLM_SOURCE` выбирает поставщика, `LLM_ADAPTER` — чем к нему ходить. Метка
сложности агента (`smart`/`medium`/`weak`) проще подборщика: называет продавца и не смотрит ни на цену, ни на
статистику.

Кто ведёт ход — [main-model](../gateway/main-model.md). Форматы вызова инструментов —
[tool-formats](../gateway/tool-formats.md).
