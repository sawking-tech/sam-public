# Контекст хода

Что модель видит на каждом ходе и как это не растёт с длиной беседы. Два механизма, работающих вместе: сжатие
удерживает контекст одного размера, хранилище разводит правду и оглавление.

| Файл | Механизм |
|---|---|
| [compression.md](compression.md) | скользящее окно: несжатые ~600 токенов дословно, старше — сводки, сводок в контексте не больше `SAM_COMPRESS_SUMMARY_CEILING` (4). Соседние сводки сливаются попарно при переполнении, самая старая постепенно вбирает всю раннюю беседу. Всё сжатое и удалённое сначала уходит в архив, монитор показывает сессию целиком |
| [storage.md](storage.md) | коллекции `sam`: `sessions` с нейтральной ролью `tool_call`, `sessions_archive`, `_memories` как источник правды, TTL задач и `_token_usage`. Схема задачи и её этапов; Qdrant пересоздаётся без потери данных, потому что текст всегда из Mongo |

Поиск по памяти на входе хода — [memory-search](../../features/memory/memory-search.md). Когда факты пишутся сами и
когда идёт обслуживание — [compression.md](compression.md), раздел о запуске.
