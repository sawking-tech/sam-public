# stand

Из каких процессов состоит стенд и что делать, когда блок упал.

Стенд поднимается одной командой (`start_sam.ps1`) и состоит из блоков, каждый в своём процессе: Docker с MongoDB,
Qdrant и n8n, синтез и эмбеддер, агрегатор MCP, клиентский агент, голосовой слой с узлом звука и мостом, шлюз и
Cortex. Надзор двусторонний: шлюз поднимает упавшие компоненты по командной строке процесса, а внешний
`scripts/stand_watch.py` следит за самим шлюзом — надзор за надзором, иначе упавший шлюз некому чинить.

| Файл | Механизм |
|---|---|
| [stand.md](stand.md) | блоки и их порты, кто кого поднимает, поиск процесса по командной строке (чужой процесс на порту не гасится), вкладка ведущего с `SAM_LEAD_*`, уборка сессий и dead-agent, потоки данных |

Упавший блок виден строкой в `/health` и логом `logs/<компонент>.log`; что делать по каждому — в
[operations/health](../../operations/health.md).
