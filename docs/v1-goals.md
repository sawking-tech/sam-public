# SAM v1: цели автора

Записано со слов автора 8 октября 2026, 23:31-23:37, голосом. Формулировки того дня не менялись.

SAM - система мониторинга, реагирования и ассистирования для большой и малой инфраструктуры, сделанная из платформы.
SAM автора - та же система со своими целями и приложениями; первая и главная цель - домашний ассистент. Цели ниже
разделены на платформу и на SAM автора.

## Платформа

- Прибраться в SAM, обновить её и дальше идти по плану.
- Научить SAM работать через агентов кода: минимум Claude Code и OpenCode.
- Claude Code - альтернативный поставщик ИИ для SAM: подключается файловой шиной, слушает тики через Monitor, пишет
  реплики в `say-out`, быстрая модель отвечает первой.
- SAM применяет скиллы так же, как Claude Code, и так же экономно.
- Скорость и расход памяти растут через архитектуру: переносить в SAM функциональность других агентных систем по
  матрице сравнения так, чтобы скорость росла, а память не тратилась зря.
- Нормы кода и порядок работы с ИИ - в `CLAUDE.md` SAM.

## SAM автора

- SAM v1 - живой голосовой напарник на локальной GLM. Голосовой слой отлажен вживую: поток синтеза, перебивание,
  опознание голосов. Тренажёр - один из режимов SAM.
- Голос SAM на этом слое, включая болталку: быстрая модель отвечает первой, основная поправляет.

## Что в v1 не входит

Направления, решённые автором 14 октября как план, а не как обязательства:

- быстрая песочница для проверок посреди разговора (сделано, `features/sandbox.md`);
- git и бэкап на каждое приложение;
- шина NATS;
- API стенда для приложений (ADR-025);
- коннекторы и связи приложений;
- магазин MCP с вопросом о доверии при обновлении (ADR-016, ADR-021);
- ядро фича-флагов (ADR-024);
- связывание наблюдений в понимание состояния людей, привычек и отклонений;
- модули и готовые сборки под другие применения: умный дом, охрана и наблюдение, расписания, завод, предприятие.
