# SAM v1: цели автора

Записано со слов автора 8 окт 2026, 23:31-23:37, голосом. Ревью SAM и сравнение с
открытыми агентами, на которых строится план, лежат рядом: `review-2026-10-08.md`, `agent-matrix-2026-10-08.md`.

SAM - система мониторинга, реагирования и ассистирования для большой и малой инфраструктуры; сделана она из
платформы, SAM автора - та же SAM с его целями и приложениями (README, «Что такое SAM»). Первая и главная цель - домашний ассистент. Цели ниже
разделены на платформу и SAM автора; формулировки 8 окт не менялись.

## Платформа

- Прибраться в SAM, обновить его и дальше идти по плану.
- Научить SAM работать через агентов кода, как минимум Claude Code и OpenCode.
- Claude Code - альтернативный поставщик ИИ для SAM. Подключается через файловую шину: слушает тики через Monitor,
  пишет реплики в say-out, быстрая модель отвечает первой.
- SAM применяет скиллы так же, как Claude Code, и оптимально.
- Скорость и расход памяти улучшаются архитектурой: переносить в SAM функциональность других агентных систем по
  матрице сравнения так, чтобы скорость только росла, а память не тратилась зря.
- Нормы кода и философию работы с ИИ перенести в `CLAUDE.md` SAM.

## SAM автора

- SAM v1 - живой голосовой напарник на локальной GLM. Голосовой слой отлажен вживую:
  поток синтеза, перебивание, опознание голосов. Тренажёр становится одним из режимов SAM.
- Голос SAM на этом слое, в том числе болталка: быстрая модель отвечает первой, основная поправляет.

## Направления платформы после v1

Решены автором 14 окт как направления, обязательствами v1 не стали. Всё ниже - план: быстрая песочница для

применения - умный дом, охрана и наблюдение, расписания, завод, предприятие.
