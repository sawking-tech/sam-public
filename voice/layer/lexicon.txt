# Словарь произношения: как слово писать для синтеза, чтобы движок прочитал его верно (voice/layer/lexicon.py).
# Строка: слово = написание [; окончания через пробел]. Слово - основа, к которой прибавляются окончания;
# фраза из нескольких слов («на связи») заменяется целиком, без окончаний;
# без списка окончаний - падежи существительного мужского рода на твёрдую согласную (стек, стека, стеком...).
# Регистр не важен, у замены он берётся из реплики. Правка файла подхватывается без перезапуска голосового слоя.

# Silero произнёс «стек» неверно, надо «стэк»
стек = стэк

# «на связи» - ударение на «я»; расстановщик ставит «связи́», как в «в связи с»
на связи = на св+язи

# «права» (полномочия): ударение на последнее «а»
права = прав+а

# «писал» - ударение на «а», расстановщик дал «пи́сал»
писал = пис+ал
