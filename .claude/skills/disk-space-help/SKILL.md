# disk-space-help

Сначала замер только на чтение, потом совет. Удалять что-либо без прямого слова человека нельзя.

## Шаги

1. Замер фоновым агентом (`spawn_agent`): свободное и общее место на дисках, затем 10-15 самых больших папок на заполненном диске. Ничего не удалять и не перемещать - только смотреть.
2. Итог одной-двумя фразами: какой диск, сколько свободно, что занимает больше всего.
3. Предложи безопасные шаги из стенда, без запуска:
   - `scripts/docker_hygiene.ps1` - чистка Docker без удаления данных;
   - `scripts/free_c_disk.ps1` - показ того, что можно убрать.
4. Запускать уборку - только после прямого «да» на конкретный шаг. Удаление личных файлов не предлагать.
