# sandbox

Песочница - мои руки для кода: изолированный контейнер без доступа к SAM и системе. Выбор инструмента зависит от
того, сколько живёт работа и нужен ли результат файлами.

## 1. Какой инструмент

- `sandbox_exec` - проверить по ходу разговора: расчёт, гипотезу, кусок скрипта, запрос к таблице. Тёплый контейнер
  беседы отвечает за миллисекунды; переменные Python и таблицы DuckDB живут между вызовами. Сети, пакетов и файлов с
  ПК нет.
- `sandbox_run` - задача с файлами: скрипт с несколькими файлами, пакет из PyPI или npm, данные с ПК, выгрузка на ПК,
  страница или график, который покажу. Повторный запуск в той же папке - `job` из прошлого ответа.

Простое правило: ответ - число или строка в разговоре - `sandbox_exec`; ответ - файл, страница или нужен пакет -
`sandbox_run`.

## 2. Сеть и пакеты

- Пакет - параметром `packages` с точной версией (`pip:six==1.16.0`, `npm:left-pad@1.3.0`): он ставится до команды и
  проверяется по базе уязвимостей; сеть команде для этого не нужна.
- `network=internet` - только когда задаче нужен интернет (скачать данные); дом и эта машина при этом закрыты.
- Публичный репозиторий - параметром `clone`, а не `git clone` в команде.

## 3. Файлы с ПК и выгрузка

- Файлы с ПК - параметром `import` из разрешённых папок (`SAM_SANDBOX_IMPORT_ROOTS`); секреты (`.env`, ключи,
  `.git`) не копируются. Папка не разрешена - так и говорю человеку, путь не угадываю.
- Готовое на ПК - параметром `export`, оно ложится в папку экспорта (`SAM_SANDBOX_EXPORT_DIR`) под своим именем;
  имя занято - беру другое. Экспорт выключен - говорю об этом и показываю результат в мониторе.

## 4. Из задачи - в приложение

Страница из песочницы становится приложением через `app_make(..., from_job=job)`: папка задачи копируется вместе с
пакетами, `files` ложатся поверх. Правка уже сделанного приложения - `app_update(slug, from_job=job)` (скилл make-app).

## 5. Отказы

| Ответ | Что делаю |
|---|---|
| пакет без точной версии или из URL | указываю версию `имя==x.y.z` |
| пакет с уязвимостью | беру исправленную версию или другой пакет |
| копия не из разрешённой папки | прошу человека положить файл в разрешённую папку |
| имя экспорта занято | выгружаю под другим именем |
| команда зависла и погашена | делю работу на части или ставлю `sandbox_run` вместо `sandbox_exec` |

Итог называю одной фразой: что посчитала или где лежит выгруженное.
